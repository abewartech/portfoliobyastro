## 1. Gemini 4 Carbon

Google memperkenalkan Gemini 4 Carbon, dan kabar ini langsung merajai Hacker News pagi ini. Bagi full stack engineer yang memakai LLM setiap hari, rilis model baru dari Google selalu layak dipantau: ia bisa mengubah pilihan model default untuk tugas coding, agen, maupun multimodal.

[Baca pengumuman resmi Google](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-carbon/)

## 2. Expo Skills

Expo merilis kumpulan agent skill untuk proyek Expo dan React Native. Skill ini membuat coding agent lebih memahami struktur proyek, perintah, dan pola kerja Expo, sehingga hasil kerjanya lebih nyambung dengan codebase yang sudah ada. Buat yang masih aktif mengembangkan aplikasi React Native, ini salah satu tambahan tooling paling praktis minggu ini.

[Lihat repo Expo Skills](https://github.com/expo/skills)

## 3. Macro

Macro adalah workspace terpadu open-source untuk tim: email, chat, dokumen, task, agen AI, dan panggilan dalam satu tempat. Konsepnya menarik bagi tim kecil yang ingin mengurangi tab dan langganan SaaS yang tersebar, sekaligus tetap punya kendali atas datanya sendiri.

[Lihat repo Macro](https://github.com/macro-inc/macro)

## 4. AI Design Skills

Repo ini berisi skill desain untuk agen AI, yang membantu coding agent menghasilkan UI yang lebih rapi dan konsisten. Masalah klasik vibe coding adalah hasil visual yang asal jadi; skill seperti ini mencoba menutup celah itu dengan panduan desain yang bisa langsung dipakai agen.

[Lihat repo AI Design Skills](https://github.com/elayadesign/ai-design-skills)

## 5. Agent Purge

Agent Purge memungkinkan satu persona dipakai di banyak coding agent: mengganti atau menyuntikkan system prompt ke Codex, Claude, OpenCode, Grok, dan lainnya lewat konsol web lokal. Buat yang memakai beberapa agen sekaligus, ini cara praktis menjaga gaya dan aturan kerja tetap konsisten tanpa mengedit konfigurasi satu per satu.

[Lihat repo Agent Purge](https://github.com/ZiChuanLan/agent-purge)

## 6. Minilytics

Minilytics adalah analitik open-source yang berorientasi revenue untuk indie hacker dan solo founder. Berbeda dengan analitik umum yang fokus pada pageview, Minilytics menekankan angka yang berhubungan langsung dengan pemasukan. Ringan dan bisa di-self-host, cocok dipasang di situs dan toko sendiri.

[Lihat repo Minilytics](https://github.com/surendrapandar/minilytics)

## 7. Cursor Agent SDK

Cursor merilis Agent SDK, perangkat untuk membangun agen sendiri di atas tooling Cursor. Ini sinyal bahwa Cursor tidak lagi sekadar editor dengan AI, tapi platform untuk membangun agen coding kustom. Buat yang sudah memakai Cursor dalam workflow harian, SDK ini membuka peluang automasi yang lebih dalam.

[Baca pengumuman Cursor](https://cursor.com/blog/agent-sdk)

## 8. Heads of Security (arXiv)

Paper ini memperkenalkan Heads of Security (HoS), pertahanan terhadap prompt injection lewat attention gate terlatih yang menegakkan pemisahan instruksi dan data di dalam model. Seiring agen LLM makin sering memproses input tak tepercaya, pertahanan di level arsitektur seperti ini menjadi riset yang penting untuk diikuti.

[Baca paper di arXiv](http://arxiv.org/abs/2610.37657v1)
