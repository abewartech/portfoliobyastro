A practical, hands-on project in the OpenWRT ecosystem: tooling that supports selling internet access through routers running OpenWRT. The work lives close to the metal — shell scripting, Python automation, and router configuration — covering the workflow of provisioning and managing routers used for voucher-based sales.

It sits at the intersection of software and networking: writing code that has to behave on constrained embedded hardware, where every megabyte of RAM and every CPU cycle counts.
